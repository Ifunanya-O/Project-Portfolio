Sentiment Analysis of Customer Reviews

- Developed a machine learning model to classify customer reviews as positive or negative using the "Product Sentiment" dataset.
- Preprocessed textual data, including tokenization, lemmatization, and TF-IDF vectorization, to optimize input for model training.
- Trained and fine-tuned a Logistic Regression classifier, leveraging grid search for hyperparameter tuning and cross-validation to enhance performance.
- Evaluated model accuracy and F1-score, analyzed incorrect predictions, and generated insights from confusion matrix and classification reports.
- Achieved 77.83% accuracy in predicting customer sentiment.
