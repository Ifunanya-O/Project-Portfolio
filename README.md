Titanic Data Project

This project, undertaken as part of the Kaggle Titanic Data Competition, involved a comprehensive analysis of passenger data to predict survival rates. The project encompassed several key stages:

Exploratory Data Analysis (EDA):

Data Exploration: Conducted in-depth exploratory data analysis to understand the dataset's structure, distribution, and relationships between features.
Data Cleaning: Utilized Pandas to clean the dataset, including handling missing values, correcting data types, and addressing inconsistencies to prepare the data for analysis.
Data Manipulation:

Custom Python Functions: Defined and implemented Python functions to manipulate and preprocess the data efficiently. This involved transforming features, encoding categorical variables, and normalizing data.
Data Visualization:

Seaborn and Matplotlib: Created various visualizations using Seaborn and Matplotlib to illustrate patterns, distributions, and relationships within the data. Visualizations included histograms, box plots, and heatmaps to support data-driven insights and model development.
